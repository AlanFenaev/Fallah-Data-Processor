# Обработчик данных Fallah

Скрипт собирает данные из папок `08_EXCEL_DIMENSIONAL__РАЗМЕРНЫЕ`, 
считает безразмерные коэффициенты q* и w* и строит сводный график.

1. Установите Python 3.9+
